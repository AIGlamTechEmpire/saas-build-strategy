## How to Use This Document

When discussing offers in any AI-generated content:
1. Use the EXACT name and price from this doc. Never invent or estimate.
2. Pull the promise language verbatim — that's the tested copy.
3. Reference the hero customer story when proof is needed.
4. Never mention an offer that isn't in this doc. If unsure, ask before claiming.

## Drafting notes

- Capture every active offer. If the user has 1 offer, that's fine. If they have 10, list all 10.
- Use exact pricing where available. If pricing varies (custom quotes), note the range and what determines the price.
- Hero customer stories are gold. One specific named customer per offer beats five vague mentions.
- If the user has a complex ascension path with branching, draw the branches.
- Don't include deprecated or sunset offers. Brain should reflect current reality.
- Mark `[TO REFINE]` for any offer where details are uncertain.
